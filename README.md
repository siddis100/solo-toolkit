## Français

Calculateurs et modèles pour micro-entrepreneurs : cotisations URSSAF 2026,
seuils de TVA, factures conformes, revenu net, versement libératoire,
suivi de revenus et planification ADHD. Gratuit, sans compte, sans cookie,
calcul 100 % local dans le navigateur.

### Barèmes 2026 utilisés

| Activité | Cotisations | CFP | Plafond CA |
|---|---|---|---|
| Vente de marchandises | 12,3 % | 0,1 % | 188 700 € |
| Services (BIC) | 21,2 % | 0,1 % (0,3 % artisan) | 77 700 € |
| Libéral non réglementé (BNC) | 26,1 % | 0,2 % | 77 700 € |

Franchise de TVA : 85 000 € (biens) et 37 500 € (services), tolérance 93 500 € / 41 250 €.
ACRE : −50 % de cotisations la première année.

```

docs/outils/     30 outils interactifs + index + 4 outils historiques
```

### Why this repository exists

Each free tool targets one precise search intent (a job title, a platform, a tax
threshold) and links to the paid template that automates the same calculation
over twelve months. The pages are static HTML with inline CSS and vanilla JS, so
they load in under 100 ms and work offline once cached.
